Welcome! Here you have access to the resources necessary to build an application for RingCX Digital. The following resources and guides can help you get started.

## Interactions

In RingCX Digital, interactions are the conversations agents have with customers across digital channels. Developers can use the Interaction API to manage and automate incoming customer engagements.

### Build a Chat Bot

One way to extend RingCX Digital is to build applications that automate customer interactions, commonly called chatbots. Chatbots provide a conversational interface to third-party systems and can assist with workflow automation.

<a class="btn btn-primary" href="./interactions/chatbots/overview/">Learn more about Chatbots &raquo;</a>

### Getting Started with Webhooks

Webhooks are essential in creating apps that respond to customers and assist agents in real-time. Webhooks are the means by which applications are notified of events happening across an account. 

<a class="btn btn-primary" href="./webhooks/">Learn more about Webhooks &raquo;</a>
